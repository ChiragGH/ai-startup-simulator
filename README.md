# AI Startup Simulator

A single-player browser idle game about growing a fictional AI startup. Collect data, buy upgrades, expand headquarters, trade fictional stocks, and unlock story dialogue.

## Preview

Open `index.html` in a modern browser. The game saves progress in local storage. It does not scrape real data, trade real assets, or call an AI service.

The original project did not contain its referenced image assets. This source release includes simple SVG tiles for the missing icons so the interface has no broken images. The artwork is a placeholder for a later visual pass.
